# Family Archive Tools — brand guide

**Proposed display name:** Family Archive Tools
**Tagline:** *From shoebox to searchable.*

## Why this name

The CLI already installs as `family-archive`; the display name follows the command. 'HistoryTools' says less than the tool does.

## The mark

A cassette tape whose ribbon spills out and becomes dashes of text — media in, transcript out.
